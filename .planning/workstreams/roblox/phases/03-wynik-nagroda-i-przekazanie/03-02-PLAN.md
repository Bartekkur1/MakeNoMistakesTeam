  <name>Task 1: Serwerowy moduł wysyłki zgłoszenia do skrzynki rodzica (SCR-03)</name>
  <files>roblox/src/server/ReportExportService.luau, roblox/src/server/MissionService.server.luau</files>
  <action>
    1. Utwórz `roblox/src/server/ReportExportService.luau`:
       - Konfiguracja: `BACKEND_URL` (domyślnie z atrybutu workspace/ServerStorage lub fallback `http://localhost:3000`), `INGEST_SECRET` (`bezpieczna-aura-roblox-2026`).
       - Metoda `exportReportAsync(player: Player, reportData: any): { success: boolean, statusText: string, reportId: string?, parentName: string? }`:
         - Buduje JSON payload w formacie skrzynki:
           `{ roblox_username = player.Name, roblox_user_id = player.UserId, attack_type = "data_request", source = "game", taken_actions = reportData.takenActions, content = reportData.content, test_outcome = reportData.testOutcome }`.
         - Używa `HttpService:RequestAsync` na endpoint `${BACKEND_URL}/api/reports/ingest` z nagłówkami `Content-Type: application/json` oraz `x-ingest-secret`.
         - Całość owinięta w `pcall`:
           - Kod 200/201: zwraca `{ success = true, statusText = "Doręczono do skrzynki rodzica", parentName = resp.parent_name or "Mama Oli (demo)", reportId = resp.report_id }`.
           - Błąd HTTP lub błąd połączenia (np. brak tunelu/localhost blokada): zwraca `{ success = false, statusText = "Zapisano w raporcie misji — gotowy do przekazania" }`.
    2. W `MissionService.server.luau`:
       - Po zakończeniu misji (`ending_safe` lub `ending_bad`) wywołaj asynchronicznie `ReportExportService.exportReportAsync`.
       - Zaktualizuj snapshot dla danego gracza o status eksportu (`exportStatus = { sent = success, message = statusText, reportId = reportId, parentName = parentName }`).
       - Wyślij zaktualizowany snapshot przez `MissionUpdate`.
  </action>
  <verify>
    <automated>cd roblox && selene src && stylua --check src && mkdir -p build && rojo build default.project.json -o build/Phase3-export.rbxlx</automated>
    <fails_when>błędy kompilacji lub brak eksportu w ReportExportService</fails_when>
  </verify>
</task>
