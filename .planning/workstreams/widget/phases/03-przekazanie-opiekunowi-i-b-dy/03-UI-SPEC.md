# Phase 03 — UI Design Contract

> Visual and interaction contract for Przekazanie opiekunowi i błędy (widget workstream; HND-01, HND-02, HND-03, ERR-01). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase adds five panel surfaces to the existing small window beside the shark (send preview, send outcome, platform instructions, Moje zgłoszenia, no-account notice) and one new extension page (parent login / options). Everything else keeps the Phase 02 contract (`02-UI-SPEC.md`) unchanged: 320px panel, Shadow DOM isolation, Scamerino palette, native controls, Polish copy for ages 9–13.

**Source precedence:** `03-CONTEXT.md` D-00…D-16 (locked) → `.planning/shared/CONTRACT.md` v2 and `projects/web-app/src/lib/contract/types.ts` (enum labels, limits, error codes; D-00 forbids changes) → `02-UI-SPEC.md` (tokens, patterns, existing copy) → web-app login pattern (`LoginScreen.tsx`, `OtpInput.tsx`, `DemoAccountsDialog.tsx`, `content.ts` `LOGIN`/`DEMO_INFO`/`escalateWhere`). Where CONTEXT left wording or layout to Claude's discretion, this document fixes it; such values are marked *(default)*. No user questions were needed: CONTEXT and the Phase 02 contract answer every design-system, spacing, typography and color question.

### Send preview layout (320px panel, top → bottom)

1. h2 **Sprawdź, co wyślesz** (existing h2 rule, 18px).
2. Recipient: `p.source`-style line — **Do:** + `account.display_name` in 15px/600 primary text on its own line (`overflow-wrap: anywhere`).
3. Label **Wiadomość** (15px/600) + read-only content box.
4. `p.hint` **Chcesz coś usunąć z treści? Wróć do wyniku i wybierz „Edytuj wiadomość”.**
5. Fieldset legend **Na co to wygląda?** (18px/600, existing legend rule) + 6 radios.
6. Fieldset legend **Co już zrobiłeś?** + `p.hint` **Zaznacz tylko to, co się stało. Jeśli nic z tego, nie zaznaczaj niczego.** + checkboxes.
7. Label **Skąd jest ta wiadomość?** (15px/600) + `select`.
8. `.notice` **Zobaczy to Twój rodzic. Wynik sprawdzania i Twoje odpowiedzi nie są wysyłane.** (D-02).
9. Outcome alert slot (empty until a failure).
10. `.row`: **Wróć** (secondary, returns to result with all preview selections kept for this case) + **Wyślij** (primary).

Vertical rhythm: 16px between blocks 3, 5, 6, 7, 8 (`margin-top: 16px`); 8px between a label/legend and its control. Initial focus goes to the content box (first reviewable item) so a keyboard user reads before sending; **Wyślij** is never auto-focused.

## Interaction & Focus Contract

- **Navigation map:** result → (**Pokaż opiekunowi**) send preview → (**Wyślij**) confirmation | alert in place; result → (**Jak zgłosić na platformie**) platform view → (**Wróć do wyniku**) result; menu → Moje zgłoszenia → (**Wróć**) menu; warning alert → Moje zgłoszenia → (**Wróć**) send preview. Every view keeps the Phase 02 resume model: close/hide and reopen restore the current view; reload/new document clears everything (no case content on disk).
- **Focus on render:** send preview → content box; failure alert → the retry button (alert is announced via `role="alert"`); confirmation → **Zamknij**; platform view → **Wróć do wyniku**; Moje zgłoszenia → **Wróć** (focus is not stolen when the list finishes loading); result → first button of the `.actions` stack.
- **Preview selections** (attack type, actions, source) persist for the current case while navigating between result, preview, platform view and list; they reset when the case content changes (Phase 02 edit rules).
- **Duplicate-send guard:** **Wyślij** is disabled from click until outcome; after 201 the case is marked sent and **Pokaż opiekunowi** no longer leads to a preview for it.
- **Login page keyboard:** Enter submits each step; filling the 4th code box submits; on `invalid_credentials` the code clears and focus returns to box 1; on step change focus moves to the step's first field; dialog returns focus to **Zobacz konta demo** on close.
- **Dragging:** new views follow the existing `onMove → panel.place()` rule; no re-render, no request during drag.
