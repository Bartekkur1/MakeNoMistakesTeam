## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| web page → content script | The page (including Discord) owns the DOM the content script runs in; its selection, events and CSS are untrusted |
| content script → service worker | runtime messages; only our own content script may send cases |
| child input → UI | selected or pasted text and links are untrusted strings rendered inside our shadow root |
| npm registry → build | third-party dev packages run during install and build |
