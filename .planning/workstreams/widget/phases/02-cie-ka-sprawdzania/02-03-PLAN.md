## State contract and dependency graph

check is the active approved session; draft is an optional unapproved edit/replacement candidate. Keep resumeStep in check so closed is only a visibility state. Starting a preview never deletes check. Candidate kind edit/replacement and a resume target disambiguate cancel/back. Copy the approved case's content into draft.text when editing; preserve link/origin/truncated. Replace check only in approved(token, approvedCase), after local acceptance. Changing either text or link resets all answers, hints, mismatch acknowledgments and result on reapproval. Reapproval of an unchanged case resumes existing progress instead of wiping it; compare normalized content and link, not created_at. New document resets both candidate and approved session and invalidates gen. These are local session decisions with no shared schema change.

Task 1 needs 02-02 and creates the end-to-end correction/reapproval transaction; task 2 expands selection/resume controls using that transaction; task 3 validates document/tab/drag and whole-phase regressions. All has_checkpoint=false. Shared files force waves 1 → 2 → 3; no same-wave shared mutable resources.
