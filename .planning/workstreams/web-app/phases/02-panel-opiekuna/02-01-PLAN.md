(4) web-app/src/app/_panel/api.ts (no "use client", no React, no server imports):
- Types `ApiFailure` = { ok: false; kind: "http"; status: number; code: ApiErrorCode; message: string; details: FieldError[] } | { ok: false; kind: "network" }, and `ApiResult<T>` = { ok: true; value: T } | ApiFailure.
- `apiCall<T>(path, { method: "GET" | "POST"; token?: string; body?: unknown })`: fetch(path) with cache "no-store", header Accept application/json, `Authorization: Bearer <token>` when a token is given, Content-Type application/json plus JSON.stringify(body) when a body is given. A rejected fetch → { ok: false, kind: "network" }. Read the body with response.json() inside try/catch (null when not JSON). 2xx with a JSON body → { ok: true, value }. 2xx without one → http failure internal_error. Non-2xx: the code is error.code from the envelope when it is one of API_ERROR_CODES, else by status (401 unauthorized, 403 forbidden, 404 report_not_found, 409 invalid_transition, 413 payload_too_large, 503 storage_unavailable, anything else internal_error); message = API_ERROR_MESSAGES_PL[code]; details = the envelope's details entries that have string field and message, else [].
- `loginRequest(email, code)`: POST "/api/auth/login" with { email: email.trim(), code: code.trim(), scope: "panel" } → ApiResult<LoginResponse>.
- `errorMessage(failure, networkMessage = ERRORS.networkLoad)`: network → networkMessage; internal_error → API_ERROR_MESSAGES_PL.internal_error + ERRORS.retrySuffix; validation_error → the first details message, else the internal_error text; any other code → API_ERROR_MESSAGES_PL[code].
- `isUnauthorized(result)`: true only for an http failure with code "unauthorized" (the login 401 invalid_credentials is not a session expiry).
- The list call `fetchReports` is added by plan 02-02 on top of apiCall; this plan's tests drive apiCall against GET /api/auth/me for the Bearer and 401 bullets.

| panel bundle → public | Everything imported by a client component ships to every visitor |
