## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → GET /api/reports | The panel sends the Bearer token and the page size; the server decides which reports the account may see |
| API response → DOM | Report content is text written by a child or a scammer and is shown as a row excerpt |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
