## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /api/reports, /api/reports/{id} | Untrusted bodies, query parameters, path ids and tokens |
| route handlers → Postgres functions | Server-computed scope and values become RPC arguments |
