## Flagged Assumptions (spec-less edge probe, API-02)

The edge probe classified API-02 as "unclassified", so its edges were authored manually and are listed here rather than silently dropped:
- Transition policy: any status → any status (reopen allowed). This is a planner choice put to osoba 2 at 01-01 Task 3, item (a). If osoba 2 required a forward-only flow, that "revise:" outcome changes Task 2 here to return 409 on backward transitions.
- A reply never changes status (item (d)).
- Invalid status → 400; unknown or malformed case → 404 for both PATCH and replies.
- Repeating the same status is idempotent and returns 200. This covers the API-01 idempotency edge for PATCH.
