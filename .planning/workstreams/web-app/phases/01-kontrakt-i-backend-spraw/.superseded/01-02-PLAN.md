(1) Create `web-app/supabase/migrations/20261003120000_cases_replies.sql` (D-05: plain SQL, no ORM). The timestamped name works with both the Supabase SQL editor and `supabase db push`.

Table `public.cases`:
- id uuid primary key default gen_random_uuid()
- demo_child_id text not null, with a check that it matches ^[A-Za-z0-9_-]{1,64}$
- source text not null, with a check in ('game','email','sms','discord','other')

- updated_at timestamptz not null default now()
- Index `cases_child_created_idx` on (demo_child_id, created_at desc, id desc).

Table `public.replies`:
- id uuid primary key default gen_random_uuid()
- case_id uuid not null references public.cases(id) on delete cascade
- message text not null, with a check that char_length(btrim(message)) is between 1 and 2000
- created_at timestamptz not null default now()
