# Quick Plan: Separate Roblox Training Reports from Widget Reports

## Objective
Separate educational Roblox game reports from real-world widget incident reports in the guardian/teacher panel (`projects/web-app`), implement deduplication for successfully passed trainings, and add distinct training metadata to game missions in Roblox (`projects/roblox`).

## Requirements
1. **Roblox Mission Metadata (`projects/roblox`)**:
   - Each training/mission in the game must have an identifier and human-readable name.
   - The current password phishing mission is defined as:
     - `training_id: "password_phishing"`
     - `training_name: "Przeciwdziałanie wyłudzaniu hasła"`
   - Passed in `ReportExportPayload` to `/api/reports/ingest`.
2. **Backend Contract, Validation & Ingest Deduplication (`projects/web-app`)**:
   - `RobloxIngestRequest` accepts optional `training_id` and `training_name`.
   - `parseRobloxIngest` validates them with backward-compatible defaults.
   - `ingestContent` includes training name and ID.
   - **Deduplication**: If a child has already completed this training positively (`outcome === "safe_refusal"`), do NOT insert a duplicate report. Return 200 OK with `already_completed: true` and the existing report ID.
3. **Guardian Panel UI Separation (`projects/web-app`)**:
   - In `ReportListView.tsx`, add a tab bar separating:
     - **Zgłoszenia z sieci** (`report.source !== "game"`)
     - **Szkolenia Roblox** (`report.source === "game"`)
   - The "Szkolenia" tab renders items via `TrainingRow.tsx`:
     - Training title ("Przeciwdziałanie wyłudzaniu hasła")
     - Educational status badge: "✓ Zaliczone" (green) vs "⚠ Wymaga powtórzenia" (amber)
     - No widget-specific panic risk badges
     - Dedicated empty state for trainings
4. **Verification**:
   - Vitest unit & integration tests in `projects/web-app` (ingest deduplication, validation, tabs, training row).
   - Selene, stylua and rojo in `projects/roblox`.

## Tasks
1. **Backend & Contract (`projects/web-app`)**:
   - Modify `src/lib/contract/types.ts`: add `training_id`, `training_name`, and `already_completed`.
   - Modify `src/lib/server/validate.ts`: parse `training_id` and `training_name`.
   - Modify `src/lib/server/roblox.ts`: prefix in `ingestContent`, implement `findCompletedTrainingReport`, and handle deduplication in `createRobloxIngestReport`.
   - Update tests in `tests/api/roblox.test.ts` and `tests/lib/schema-mirror.test.ts`.
2. **Roblox Mission (`projects/roblox`)**:
   - Update `src/shared/MissionContent.luau`: add `trainingId` and `trainingName`.
   - Update `src/server/ReportExportService.luau`: add `training_id` and `training_name` to `ReportExportPayload`.
   - Update `src/server/MissionService.server.luau`: attach training info in export payload.
   - Run `selene` and `stylua`.
3. **Panel UI (`projects/web-app`)**:
   - Create `src/app/_panel/TrainingRow.tsx`.
   - Update `src/app/_panel/ReportListView.tsx` with tab bar ("Zgłoszenia z sieci" vs "Szkolenia Roblox").
   - Update `src/app/_panel/ReportCards.tsx` to display training badge when source is "game".
   - Add/update tests in `tests/panel/list-flow.test.ts` or dedicated test file.
