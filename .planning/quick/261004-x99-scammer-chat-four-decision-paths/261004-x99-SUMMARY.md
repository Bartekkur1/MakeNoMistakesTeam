## Key Changes
1. **Shared Content & Data Model ([`MissionContent.luau`](file:///Users/robert/Documents/Projects/hackyeah2026/MakeNoMistakesTeam/roblox/src/shared/MissionContent.luau))**:
   - Added `RuleCardInfo` data structure with official Roblox documentation source URL (`https://en.help.roblox.com/hc/en-us/articles/203313380-Account-Security-Theft-Prevention`) and verification date (`2026-10-04`).
   - Defined stage-specific choice sets:
     - `initialChoices` (`decision`): `refuse`, `check_offer`, `ask_for_help`, `share_fake_password`.
     - `refusalChoices` (`refusal_pressure`): `refuse_final`, `check_offer`, `ask_for_help`, `share_fake_password`.
     - `afterCheckChoices` (`decision_after_check`): `refuse_final`, `ask_for_help`, `share_fake_password`.
     - `afterHelpChoices` (`decision_after_help`): `refuse_final`, `share_fake_password`.
   - Added complete dialogue lines for refusal pressure, scammer excuses, public helper undermine bubble (D-13), Scamerino guidance, and compromise warnings.

2. **Server State Machine ([`MissionService.server.luau`](file:///Users/robert/Documents/Projects/hackyeah2026/MakeNoMistakesTeam/roblox/src/server/MissionService.server.luau))**:
   - Added `refusalCount` and `helpReceived` tracking to per-player state.
   - Dynamic stage transitions:
     - `refuse`: First refusal triggers manipulative delay (*"Czekaj, przecież możesz potem od razu zmienić hasło!..."*) and transitions to `refusal_pressure`.
     - `refuse_final`: Second refusal ends the encounter (*"Dobra, twoja strata. Jak nie chcesz, to nie."*), releases NPC ownership, and delivers `ending_good`.
     - `check_offer`: MatiBuilds gives group authorization excuse, then opens `rule_card` displaying official rules.
     - `close_rule_card`: Returns smoothly to `decision_after_check`.
     - `ask_for_help`: Fires public bubble on MatiBuilds head (*"On przesadza, po co go wołasz? Przecież to tylko giveaway!"*), unlocks Scamerino tab with advice, and transitions to `decision_after_help`.
     - `share_fake_password`: Fictional password submission with no text input (D-02); triggers gloat, release, and `ending_bad`.
     - `replay`: Resets state, clears conversation histories, increments revision, releases NPC, and teleports player to `MissionStart` (D-29).

3. **Client Interface ([`MissionController.client.luau`](file:///Users/robert/Documents/Projects/hackyeah2026/MakeNoMistakesTeam/roblox/src/client/MissionController.client.luau))**:
   - Added responsive `RuleCardFrame` displaying official Roblox account security guidelines and source URL.
   - Added red alert border and compromise subtitle on `ending_bad`.
   - Dynamic button layout supporting 1 to 4 buttons without clipping or overlapping messages.
   - Tab switching between MatiBuilds and Scamerino conversations with separate histories.
