# Quick Plan: Implement Four Decision Paths in Scammer Chat

## Objective
Implement all 4 decision paths in the simulated private chat with MatiBuilds, adhering to architectural decisions D-02, D-12, D-13, D-15, D-19, D-25, D-26, D-27, D-28, and D-29:
1. **Double Refusal (`refuse`)**:
   - First refusal triggers scammer pressure / manipulation (*"Czekaj, przecież możesz potem od razu zmienić hasło! Nic nie ryzykujesz, a 1500 Robuxów przepada za minutę."*) and transitions to `refusal_pressure` with updated choices.
   - Second refusal finishes the pressure (*"Dobra, twoja strata. Jak nie chcesz, to nie."*), releases the NPC, and delivers `ending_good`.
2. **Offer Check & Rule Card (`check_offer`)**:
   - Asks why the password is required.
   - Scammer gives an excuse (*"Bo wysyłam je przez panel grupy i system wymaga autoryzacji konta odbiorcy..."*).
   - Server transitions to `rule_card` presenting official Roblox security rules with verified URL (`https://en.help.roblox.com/hc/en-us/articles/203313380-Account-Security-Theft-Prevention`, verified 2026-10-04).
   - Closing the rule card returns to chat (`decision_after_check`) allowing the player to make their choice.
3. **Request Help (`ask_for_help`)**:
   - Player calls Scamerino for help in the chat.
   - Scammer shows public speech bubble undermining helper (D-13: *"On przesadza, po co go wołasz? Przecież to tylko giveaway!"*).
   - Unlocks/populates Scamerino's private chat tab with guidance and tips.
   - Allows switching between MatiBuilds and Scamerino tabs, then continues to `decision_after_help`.
4. **Fictional Password Submission (`share_fake_password`)**:
   - Dedicated button with zero text input fields (D-02).
   - Scammer gloats (*"Haha, dzięki za darmowe konto i rzadkie itemy! Nara frajerze!"*) and walks away.
   - Simulated account compromise warning (D-28) with `ending_bad` explanation and replay button.
5. **Full Replay / Re-attempt (`replay`)**:
   - Replay resets state, clears histories, increments revision, resets NPC, and teleports player to `MissionStart` (D-29).

## Tasks
1. **`roblox/src/shared/MissionContent.luau`**:
   - Expand `ChoiceRecord` and choices for stages: `decision`, `refusal_pressure`, `decision_after_check`, `decision_after_help`.
   - Add `RuleCardInfo` and official Roblox security rules source metadata.
   - Add dialogue texts for scammer excuses, pressure statements, Scamerino tips, and compromise alerts.
2. **`roblox/src/server/MissionService.server.luau`**:
   - Track `refusalCount` in player state.
   - Implement server state transitions for `check_offer`, `close_rule_card`, `ask_for_help`, `refuse` (1st and 2nd), and `share_fake_password`.
   - Fire public speech bubble on MatiBuilds when help is requested.
   - Update `send()` snapshot with dynamic choices, rule card info, and active tabs.
3. **`roblox/src/client/MissionController.client.luau`**:
   - Render rule card modal/card when `snapshot.status == "rule_card"`.
   - Support dynamic choice heights and actions across all 4 decision stages.
   - Render simulated compromised account banner on `ending_bad`.
   - Support seamless tab switching between MatiBuilds and Scamerino.
4. **Verification**:
   - Run `selene src`, `stylua --check src`, and `rojo build`.
   - Playtest in Roblox Studio: test all 4 paths, verify double refusal, rule card, Scamerino chat tab, and replay reset.
